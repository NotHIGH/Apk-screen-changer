# Screen Changer

Базовий Android-застосунок для вибору співвідношення сторін робочої області від
4:3 до поточного співвідношення екрана.

## Можливості

- визначає фактичну ширину та висоту дисплея;
- формує список поширених співвідношень від 4:3 до поточного;
- показує preview обраної області та її розраховані розміри;
- дозволяє застосувати область до вікна застосунку.

Android не дозволяє звичайному застосунку змінювати фізичну роздільну здатність
усього пристрою без системних привілеїв, root або ADB. Тому поточна версія
змінює співвідношення робочої області цього застосунку. Для системної зміни
потрібен окремий privileged/ADB-модуль.

## Збірка

```bash
gradle :app:assembleDebug
```

APK буде створено у `app/build/outputs/apk/debug/app-debug.apk`.
