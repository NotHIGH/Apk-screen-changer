# Screen Changer

Застосунок змінює системну логічну роздільність дисплея на 16:9 або 4:3 через
Shizuku та Android-команду `wm size`.

## Використання

1. Встанови та запусти [Shizuku](https://shizuku.rikka.app/). На Android 11+
	запусти його через Wireless debugging.
2. Відкрий Screen Changer, натисни `16:9` або `4:3` та надай застосунку дозвіл
	Shizuku.
3. Повторно натисни активний режим, щоб повернути стандартну роздільність.

Shizuku має бути запущений. Після перезавантаження телефона його може знадобитися
запустити знову. Щоб вручну відновити стандартну роздільність через ADB, виконай
`adb shell wm size reset`.

Застосунок змінює логічний розмір дисплея, не фізичну роздільність панелі. Це
впливає на всю систему; окремі застосунки можуть ігнорувати ці параметри.

## Збірка

```bash
gradle :app:assembleDebug
```

APK буде створено у `app/build/outputs/apk/debug/app-debug.apk`.
